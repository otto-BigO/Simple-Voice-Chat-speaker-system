# Simple Voice Chat speaker system

Lets you stick a microphone head on a wall and a speaker head somewhere else, talk into the mic, and have your voice come out of the speaker. Runs on top of Simple Voice Chat. Server-side only, vanilla clients can join no problem.

If you put a few speakers on the same label they all play together, so you can wire up a whole room or a whole base.

There's a Modrinth page with screenshots, downloads, and the full feature list if you want the polished version of all this.

## Building from source

```sh
./gradlew build
```

The jar lands in `build/libs/`. Drop it into the server's `mods/` folder.
